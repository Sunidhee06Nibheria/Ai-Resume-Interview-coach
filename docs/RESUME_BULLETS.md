# Resume Bullet Points

- Built an AI Resume & Interview Coach using FastAPI, Streamlit, SQLite, and modular agent workflows for ATS analysis, job matching, skill-gap planning, and mock interview feedback.
- Designed a RAG pipeline with chunking, embedding, retrieval, and context injection to ground resume and interview recommendations in career best practices.
- Implemented explainable scoring models for resume quality, ATS fit, technical depth, leadership, project quality, employability, and interview readiness.
- Created production-ready project structure with typed Pydantic schemas, document parsers, persistence layer, tests, Docker support, and deployment documentation.
