# LinkedIn Launch Post

I built an AI Resume & Interview Coach as a portfolio-grade full-stack AI project.

It helps users upload resumes, analyze ATS fit, compare against job descriptions, find missing skills, generate learning roadmaps, practice interviews, and receive structured feedback.

What I focused on:

- Agentic AI architecture with specialized resume, ATS, career, skill-gap, interview, and report agents
- RAG pipeline for career and interview best practices
- Explainable scoring instead of black-box advice
- FastAPI backend and Streamlit dashboard
- SQLite persistence, tests, Docker, and deployment docs

This project helped me think beyond prompts and build a real AI product workflow: ingestion, retrieval, orchestration, scoring, UX, and deployment.
